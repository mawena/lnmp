Installation

Documentation d'installation

Deux étapes : installer le paquet depuis le dépôt APT, puis lancer l'installation de la pile. Les dépendances (Nginx, MariaDB, PHP, Certbot) sont gérées automatiquement.

1 Ajouter le dépôt et installer le paquet

$ echo "deb [trusted=yes] https://mawena.cloud/repo /" | sudo tee /etc/apt/sources.list.d/mawena.list && sudo apt update && sudo apt install lnmp

2 Installer et configurer la pile

$ sudo lnmp install

L'installation est idempotente (elle reprend à la dernière étape réussie) et vous demande deux choses : le domaine par défaut (ex. mawena.cloud, ou test pour un usage local) et le mot de passe du panneau web. À la fin, le panneau est accessible sur http://admin.lnmp.

Prérequis : Ubuntu 22.04+ avec accès sudo. Pour le HTTPS, le domaine doit pointer vers le serveur.

De zéro à en ligne, dans l'ordre

Cinq commandes suffisent pour installer la pile et publier une application sécurisée.

1

Installer la pile

sudo lnmp install

Nginx, MariaDB, PHP et Certbot, plus le groupe de travail webdev.

2

Ajouter une application

sudo lnmp add

Renseignez un identifiant, un domaine et le chemin du dossier public : le vhost est créé et activé.

3

Provisionner la base

sudo lnmp db-create monapp

Base, utilisateur dédié et mot de passe généré, affiché une seule fois.

4

Activer le HTTPS

sudo lnmp add-ssl monapp

Certificat Let's Encrypt et redirection automatique vers HTTPS.

5

Vérifier

sudo lnmp doctor

Un état complet de la pile : ● actif pour chaque service en bonne santé.

Utilisation

Documentation d'utilisation

Toutes les actions sont accessibles de trois façons équivalentes : le menu interactif, la ligne de commande, et le panneau web.

Menu interactif ou commandes directes

Lancez sudo lnmp sans argument pour le menu numéroté, ou utilisez les commandes directement pour scripter.

$sudo lnmp add --id blog --domain test

Domaines multiples (local façon Laragon)

Déclarez un domaine local : LNMP gère alors /etc/hosts automatiquement pour chaque application.

$sudo lnmp domain add test --local

Ajouter une application

Choisissez le domaine de base : l'URL devient <id>.<domaine> (ou le domaine racine avec --apex). Pour un domaine local, l'entrée hosts est créée toute seule.

$sudo lnmp add --id shop --domain mawena.cloud

Bases de données

Une commande crée la base, l'utilisateur dédié et un mot de passe (affiché une seule fois).

$sudo lnmp db-create shop
Interface web

Piloter LNMP depuis le navigateur

L'installation déploie un panneau d'administration : applications, SSL, domaines, bases de données et opérations système, dans une interface conviviale.

http://admin.lnmp Lié à 127.0.0.1 et protégé par mot de passe. En local, ajoutez 127.0.0.1 admin.lnmp à votre poste ; sur un VPS, passez par un tunnel SSH.

↳ Accès distant à un VPS (tunnel SSH)

$ ssh -L 8080:127.0.0.1:80 utilisateur@mon-vps # puis ouvrez http://localhost:8080

Le panneau exige une authentification. Réinitialisez le mot de passe à tout moment avec sudo lnmp set-password.

Référence

Toutes les commandes

Chaque action est disponible en commande directe (scriptable) comme dans le menu interactif.

Commande Description
Global
lnmp install Installer ou reprendre l'installation de la pile.
lnmp uninstall Désinstaller complètement la pile.
lnmp doctor Diagnostiquer services, config Nginx et certificats.
lnmp -v Afficher la version.
Applications
lnmp list Lister les applications et leur statut.
lnmp add Ajouter une application (vhost + activation).
lnmp enable <id> Activer une application.
lnmp disable <id> Désactiver une application.
lnmp delete <id> Supprimer une application.
lnmp reload-app Reconstruire le registre depuis Nginx.
Domaines
lnmp domain list Lister les domaines de base.
lnmp domain add <nom> Ajouter un domaine (--local pour du local).
lnmp domain remove <nom> Retirer un domaine de base.
SSL — Let's Encrypt
lnmp add-ssl <id> Générer un certificat SSL + redirection HTTPS.
lnmp remove-ssl <id> Retirer un certificat SSL.
Bases de données — MariaDB
lnmp db-create <nom> Créer une base + utilisateur dédié.
lnmp db-list Lister les bases de données.
lnmp db-drop <nom> Supprimer une base de données.
Interface web
lnmp set-password Définir le mot de passe du panneau (admin.lnmp).
